PinWhere 0.3.0：安装前请先了解使用条件

将 PinWhere.app 拖到 Applications 只完成文件安装，不能直接实现免配置置顶。

当前实现需要：
1. 兼容的 Apple Silicon Mac。目前只在 macOS 27.0.1（26A434）验证成功。
2. 进入恢复模式部分关闭 SIP，并设置 arm64e 启动参数；这会降低系统保护。
3. 以管理员权限安装、加载 PinWhere 的 Dock 扩展。
4. 为 PinWhere 和包内 yabai 后端分别授予窗口控制权限。
   macOS 27 的入口名为“设备控制和数据访问”，旧版为“辅助功能”。
5. 启动后台；目前重启 Mac 或 Dock 后需要重新加载扩展。
6. 当前管理脚本启动后台时依赖 /usr/bin/python3；脚本尚未改为原生安装向导。

当前构建只有临时签名，尚未获得 Developer ID 签名和 Apple 公证。
从互联网下载后可能触发系统门禁检查；制作 DMG 不会自动消除该限制。

系统设置、扩展加载和用户授权不是 DMG 能自动代办的步骤。
如果你要求“下载、拖入 Applications、打开就能使用”，当前版本不符合这一要求。

详细安装、日常启动、恢复与卸载见同目录“使用说明.txt”。
